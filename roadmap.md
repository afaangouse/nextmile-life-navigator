# NEXTMILE roadmap

## Stage 1: foundation (this build)
- [ ] Visual identity, app shell, nine sections
- [ ] Goals, tasks, planner on browser-saved sample data
- [ ] Rule-based planning engine: priorities, conflicts, day rebalance, missed-task recovery
- [ ] Approval workflow, permission levels, audit trail

## Stage 2: accounts and saved data
- [ ] Lovable Cloud: sign-up, sign-in, password recovery (email and password, chosen by user)
- [ ] Database tables with per-user privacy; swap the browser store for the database
- [ ] Account deletion, server-side permission checks

## Stage 3: AI intelligence
- [ ] Language-model assistant through built-in Lovable AI (user chose this)
- [ ] Structured, validated recommendations and tool calls from the model

## Stage 4: proactive assistant
- [ ] Scheduled morning/evening/weekly check-ins with real background notifications

## Stage 5: integrations
- [ ] Calendar, screen-time, wearables
